# Comparative Macroeconomic Analysis: Unemployment Dynamics, Gender Gaps, and the Misery Index (1995–2024)

This repository contains an empirical macroeconomic study investigating labor market dynamics, gender disparities, and economic distress across 8 heterogeneous economies over a 30-year span (1995–2024) utilizing World Bank development indicators.

---

## 📌 Project Overview
Labor market indicators serve as vital barometers for structural economic health and resilience against external shocks. This project evaluates:
- Long-term trends in total unemployment rates across diverse economies.
- Gender-differentiated unemployment rates to capture female vs. male vulnerability across economic cycles.
- **Okun's Misery Index** ($MI = \text{Unemployment Rate} + \text{Inflation Rate}$) to decompose cost-of-living and stagflationary pressures.
- Macroeconomic resilience during key global disruptions (e.g., the 2008 Global Financial Crisis, the 2012 Eurozone Debt Crisis, and the 2020 COVID-19 pandemic).
